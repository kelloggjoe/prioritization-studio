# Prioritization Studio

A buildless, browser-based product prioritization workspace. Adjust the scoring model, edit the sample initiatives, add your own, and see the queue re-rank immediately. Data is stored only in the browser with `localStorage`.

## Run locally

Open `index.html`, or serve the directory with any static HTTP server.

## Product choices

- Transparent weighted scoring instead of a hidden recommendation engine
- Inline editing to make working sessions fast
- Accessible dialog, keyboard focus states, mobile reflow, and reduced-motion support
- Demo content is illustrative and can be reset at any time
